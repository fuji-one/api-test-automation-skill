# 长链路缺失码值补充清单

## 填写说明

- 本文档只列出长链路执行级用例中仍缺失、且无法由源码、DB MCP、前置 API、DB 造数、运行时证据或已填执行配置自动闭合的码值字段。
- 请按每行的字段含义填写真实可执行值、密钥引用、文件引用、sandbox/mock/callback 证据引用或账号引用。
- 外部依赖码值不能用本地 DB 造数替代；支付、短信、Apple/Google、审核、OSS、回调、风控等字段必须填写 sandbox/mock/callback 或真实前置接口返参证据。
- 填写完成后，流水线会把这些值回填到执行级用例、`前置数据构造规则.md` 和 `execution_fact_sources.yaml`，再进入脚本生成。

## 字段类型说明

| 需要补充类型 | 含义 | 是否可 DB 造数 |
|---|---|---|
| `precondition_api_value` | 可通过前置接口创建或查询得到的本地业务码值 | 否，优先前置 API；API 不满足时才可转 SQL |
| `db_seeded_value` | 只能通过本地 DB 构造的业务对象或状态值 | 是，但必须有源码表范围、归属键、清理规则和 SQL exit gate |
| `dictionary_or_config_value` | 来自字典表、配置表、枚举或状态表的码值 | 可查询或引用，不应随意新增 |
| `prior_runtime_response_value` | 来自同一长链路前序步骤真实响应的动态值 | 否，必须通过变量提取获得 |
| `external_dependency_value` | 来自外部服务、第三方 SDK、回调或 sandbox/mock 的码值 | 否，必须提供外部证据或合法回调载荷 |
| `account_or_role_value` | 需要特定账号、角色、租户、权限或业务状态才能产生的值 | 账号本身需用户提供；业务状态可由前置造数闭合 |
| `file_or_certificate_value` | 上传文件、证书、私钥、签名材料或 SDK 配置引用 | 否，必须提供文件或密钥引用 |

## 回填要求

- 每个 `补充项ID` 都必须填写 `用户填写值或引用`，或明确标记为 `不执行/阻塞` 并说明原因。
- 若字段需要特定账号，请填写已有账号引用，不要直接写明文密码、token、Authorization、Cookie 或原始 secret。
- 填写值必须能被脚本执行：可为普通码值、`${变量名}`、`secret_ref:xxx`、`file_ref:xxx`、`sandbox_ref:xxx`、`mock_ref:xxx`、`callback_payload_ref:xxx` 或 `precondition_api_ref:xxx`。
- 填写完成后不得直接进入脚本生成，必须先回填执行级用例并重新通过执行级准出检查。
